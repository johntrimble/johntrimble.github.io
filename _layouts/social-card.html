Not part of the normal site: only reachable via a page in the `social_cards` collection, which only exists when building with the merged `_config.yml,_config.social.yml` config (see tools/social-image.sh). Deliberately does not inherit `default`/`compress` (sidebar/topbar/TOC/footer chrome) — it links the real compiled theme stylesheet so colors/fonts match the site, then lays out a fixed-size card with its own minimal CSS. Typography note: sizes are scaled up for a 1080px canvas, but font-family and font-weight are deliberately NOT overridden — the theme's own `h1` rule (%heading: Lato 400, var(--heading-color)) and body font (Source Sans Pro) apply, so the card matches the real post page.
